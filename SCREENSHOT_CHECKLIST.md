# Screenshot Checklist

Capture the following screenshots for your final college report to perfectly demonstrate the Incremental Development Model and the Smart Waste Monitoring functionality.

### 1. Login Page
- **What should be visible:** The EcoBin login screen with username/password fields and demo credentials listed.
- **Why it is important:** Demonstrates authentication and role-based access control.
- **Report Section:** Increment 1 / System Access.

### 2. Dashboard Overview
- **What should be visible:** The 4 top metric cards (Total Bins, Normal, Almost Full, Full/Overflowing) and the Chart.js bar chart.
- **Why it is important:** Shows the high-level system analytics and the modern UI.
- **Report Section:** Increment 4 (Analytics) / User Interface Design.

### 3. Bin Management List
- **What should be visible:** The table of bins, showing ID, Type, Capacity, and the visual progress bars representing fill levels.
- **Why it is important:** Proves the CRUD functionality and database structure.
- **Report Section:** Increment 1 (Foundation).

### 4. Bin Details View
- **What should be visible:** The specific details of a bin (e.g., B004) showing its location, type, and the large circular/progress indicator for fill level.
- **Why it is important:** Displays individual tracking.
- **Report Section:** Increment 1 / Module Description.

### 5. Sensor Simulation Button
- **What should be visible:** The "Simulate Sensor Update" section on the Bin Details page.
- **Why it is important:** Proves how you overcame the lack of physical hardware by building a software simulation.
- **Report Section:** Increment 2 (Smart Monitoring).

### 6. Alert Generated
- **What should be visible:** The green success/warning flash message stating "Sensor data updated successfully... Alert generated." and the Active Alerts widget.
- **Why it is important:** Demonstrates automatic threshold detection and reactive logic.
- **Report Section:** Increment 2 / Testing Results.

### 7. Collection Request Created
- **What should be visible:** The "Collection Management" table showing a new "Pending" request with a High priority tag.
- **Why it is important:** Shows the automation linking alerts to actionable operational requests.
- **Report Section:** Increment 5 (Optimization & Automation).

### 8. Vehicle Assignment Modal
- **What should be visible:** The assignment modal open, showing the dropdown selection for Vehicles and Staff.
- **Why it is important:** Demonstrates the operational management workflow.
- **Report Section:** Increment 3 (Collection Management).

### 9. Collection Completed
- **What should be visible:** The collection table showing a request marked as "Completed" (green badge).
- **Why it is important:** Shows the end of the lifecycle. *Bonus: Take a screenshot of the bin resetting to 0% Empty.*
- **Report Section:** Increment 3 / Testing Results.

### 10. Analytics Page
- **What should be visible:** The pie chart showing distribution and the key metrics (Average Fill Level, Total Collections).
- **Why it is important:** Demonstrates data processing and visual reporting.
- **Report Section:** Increment 4 / Results & Interpretation.

### 11. Incremental Development Model Page
- **What should be visible:** The vertical timeline showing Increment 1 through 5 with descriptions.
- **Why it is important:** **THIS IS THE MOST CRITICAL SCREENSHOT.** It directly ties your prototype to your assigned CIAP topic.
- **Report Section:** Design & Methodology.

### 12. About / SDG Alignment
- **What should be visible:** The About page specifically highlighting SDG 9 and SDG 11.
- **Why it is important:** Proves the project meets the sustainability and innovation requirements of the rubric.
- **Report Section:** SDG Alignment / Conclusion.
