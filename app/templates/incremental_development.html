Project Evolution

This page visually demonstrates how the Smart Waste Collection Monitoring System was built using the Incremental Development Model.

Software Engineering Concept:
"Instead of developing the complete system at once, the system was developed and delivered in functional increments. Each increment added usable functionality to the previous version, allowing for easier testing, debugging, and continuous improvement."

  • Increment 1: Basic Management

    Foundation Phase

    Objective:

    Establish the core infrastructure and basic CRUD operations for waste bins.

    Features Delivered:
    • Admin & Operator Login
    • Dashboard scaffolding
    • Add/Edit/Delete Bins
    • View bin list
    Testing Outcome: Database connected successfully. User authentication functioning. Bin records stored persistently.

  • Increment 2: Smart Monitoring

    Core Logic Phase

    Objective:

    Introduce "Smart" capabilities by simulating IoT sensor data and automatic status calculations.

    Features Delivered:
    • Sensor simulation button
    • Dynamic fill level update
    • Automatic threshold detection (Normal, Full, etc.)
    • Alert generation for overflowing bins
    Testing Outcome: Status thresholds correctly calculated. Alerts generated when fill level > 80%.

  • Increment 3: Collection Management

    Operational Phase

    Objective:

    Enable actionable responses to the data generated in Increment 2.

    Features Delivered:
    • Create collection requests
    • Assign vehicles and staff
    • Status tracking (Pending, In Progress, Completed)
    • Auto-reset bin status on completion

  • Increment 4: Analytics & Reporting

    Data Insights Phase

    Objective:

    Provide a high-level view of system performance and data trends using Chart.js.

    Features Delivered:
    • Dynamic Dashboard charts
    • System Analytics page
    • Fill status distribution pie chart
    • Aggregated metrics calculation

  • Increment 5: Optimization & Automation

    Polish & Smart Feature Phase

    Objective:

    Introduce an innovative feature to align with SDG 9 and conclude the project.

    Features Delivered:
    • Auto-Collection Trigger: When a bin hits critical levels during sensor simulation, the system now automatically generates a pending collection request with High priority.
    • UI/UX Polishing
    Final Outcome: A complete, working prototype demonstrating the Incremental Development Model applied to a smart city problem.
