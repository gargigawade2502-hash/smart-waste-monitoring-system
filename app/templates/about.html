Smart Waste Collection Monitoring System

Software Engineering Practices - Micro Project

Project Overview

  • Development Model: Incremental Development Model
  • Course: Software Engineering Practices (SEP)
  • Type: Individual Academic Project
SDG Alignment

SDG 9 – Industry, Innovation and Infrastructure: This project supports this goal by demonstrating a technology-driven, scalable software solution to modernize municipal waste management operations through innovative simulated IoT integrations.

SDG 11 – Sustainable Cities and Communities: By optimizing waste collection routes and preventing overflowing bins, the system directly contributes to creating cleaner, healthier, and more sustainable urban environments.

Problem Statement

Traditional waste collection relies on fixed schedules and static routes, leading to overflowing bins in busy areas and wasted fuel checking empty bins in quiet areas. This lack of real-time data causes hygiene issues and operational inefficiency.

Proposed Solution

A web-based Smart Waste Collection Monitoring System that simulates IoT sensor data to track bin fill levels in real-time. The system automatically alerts administrators when bins are full and facilitates dynamic, priority-based assignment of collection vehicles.
